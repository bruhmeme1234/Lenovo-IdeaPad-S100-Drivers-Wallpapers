# Lenovo-IdeaPad-S100-Drivers-Wallpapers
This repository will house the drivers and default wallpaper found on the IdeaPad S100 restore disc

This will include the following:
- Default Lenovo Wallpapers (All 4 of them)
- Audio Driver
- Bluetooth Driver
- Card Reader Driver
- Chipset Driver
- Energy Management
- Intel AHCI Driver
- Lan Driver
- One Key Recovery
- OSD
- Touchpad Driver
- VGA Driver
- Wireless LAN Driver
